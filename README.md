## 一、make.fun 是什么，钱从哪来

make.fun 是一个「AI 编程赏金」平台。主办方（多数是平台自己）把任务挂出来当竞赛：写一个程序、做一个小应用、画一张图、写一篇教程……每场比赛写明奖金池和名次分配，比如总奖金 $1000，第一名 $150、前 50 名都有钱。

- 奖金是 **USDC**，一种和美元 1:1 的稳定币，走 **Solana** 链。
- 比赛开赛时，奖金就锁进链上的托管合约里，不是「主办方心情好才发」。
- 名次出来之后，你自己去领奖页面把钱领到你的钱包，平台不代管。

说实话：参赛不等于赚钱。热门比赛动不动上万条提交，拿名次要靠作品质量。但很多比赛**免费参加**，交一次作品的成本只有你和 AI 助手的时间，所以值得挑合适的打。

## 二、开始之前，准备这三样

1. **一个 AI 助手**：能读写文件、能运行命令的那种（Claude Code、Codex、Cursor 里的 Agent 等都可以）。make.fun 的整个流程就是为「人指挥、AI 干活」设计的。
2. **一个 GitHub 账号**：绝大多数比赛的作品要放在一个公开 GitHub 仓库里提交。没有就先去 github.com 注册一个，免费。
3. **（可选）一个 Solana 钱包**：比如 Phantom。不装也行——注册时平台可以让你的 AI 助手在本机生成一个新钱包，奖金照样打到那个钱包地址。等你真赢了，再学怎么把 USDC 转出来也不迟。

## 四、第二步：看懂一个比赛页面

打开任意一场比赛，先看四件事：

- **奖金池和名次表**：总奖金多少、发到第几名、第一名多少。有的比赛总奖金看着大，但头奖很薄、提交上万，性价比要自己算。
- **截止时间**：页面写的是 UTC 时间，换算成北京时间要 +8 小时。**截止前最后一次提交**才是你的最终作品。
- **提交数**：已经有多少条作品。和你抢名次的就是这些人（和他们的 AI）。
- **要求（Requirements）**：点开看清楚前置条件和交付物。不满足前置条件就别硬上，比如要求绑定 GitHub、要求有 YouTube 频道、要求某个软件版本——先逐条核对，缺什么补什么，补不了就换一场比赛。

## 五、第三步：新手第一场，挑这种

- **每日新闻图类**：让程序生成一张「当天世界新闻」图，AI 评审两两对决排名。作品小、流程短，最适合拿来跑通全流程。
- **教程/邀请类**：写一篇像本文这样的教程放进 GitHub 仓库，比谁带来的真实注册多。不用写代码。
- **预测/数据类**：给一份数据，按格式交一份预测文件，评分是数学公式，适合让 AI 助手慢慢磨。

先别碰的：几天内要从零做一个完整游戏、复刻一个大系统的比赛。那种是给成熟团队和老手准备的，新手第一场最重要的是**完整走完一次流程**，不是奖金大小。

## 六、第四步：开工和提交（核心流程）

每场比赛页面都能下载一个 **kit**（工具包），里面有规则文件（RULES.txt）、参赛要求和官方命令行工具。标准流程是：

1. **下载并解压 kit**，先把 RULES.txt 从头读一遍，尤其是交付物和截止时间。
2. **建仓库**：在 GitHub 上建一个公开仓库（比赛开始之后建的才算数），或者按 kit 的 `init` 命令建一个本地「源码包」仓库——有些比赛没 GitHub 也能交。
3. **让 AI 助手开工**：把任务讲清楚，让它在仓库里把作品做出来，做完你自己先看一眼效果。
4. **打包会话记录（transcripts）**：这是 make.fun 特有的规矩。提交时要附上「AI 助手干活的会话记录」，证明作品真是你的助手现做的，不是抄来的开源代码。用 kit 的 `bundle` 命令打包，它会自动脱敏（邮箱、地址这类会被抹掉）。
   - 注意：干活的会话要在**比赛开始之后**开启，开始之前的会话不算数。
5. **提交**：用 kit 的 `submit` 命令，带上仓库地址和提交号（commit sha）。提交后平台会依次跑检查：规则检查、会话记录检查、作品运行检查，然后给出临时评分。
6. **盯状态**：在「我的参赛」里看检查结果。被拒了会写明原因和改法，在截止前改好重交就行（每天有提交次数上限，别乱试）。

## 七、第五步：领奖

- 结果公布后，中奖作品旁边会出现领奖入口。
- 奖金从托管合约领到你账号绑定的钱包（注册时生成的钱包或你自己的钱包都行）。
- 领 USDC 需要钱包里有一丁点 SOL 付链上手续费，没有的话先从交易所买几美元的 SOL 转进去。

## 八、新手避坑清单

- ⏰ **时区**：所有截止先换算成自己的时区再定闹钟，别卡着点交。
- 🗂️ **仓库要公开且是自己的**：要求绑定 GitHub 的比赛，仓库必须在绑定的账号名下，赛后复查前别改成私有、别改内容。
- 🎙️ **会话记录别造假**：交别人会话、拿现成开源代码冒充，检查能看出来，直接取消资格。
- 💸 **付费报名先看清**：少数比赛要报名费，那是真花钱，AI 助手不该替你自作主张付。
- 🔁 **别重复注册小号**：一人一号，团队也用一个号参赛。
- 🖼️ **作品先自查规格**：图片大小、文件格式、字段齐不齐，规则里都写了，交之前让助手按清单核一遍。

## 九、常见问题

**Q：我不会编程，能参加吗？**
能。流程是「你定方向、AI 干活、你验收」。教程类比赛连代码都没有。

**Q：参加一场比赛要花钱吗？**
多数免费。个别比赛有报名费，页面会写明，没写就是免费。

**Q：奖金多久到账？**
结果公布后自己领，领了就到钱包，链上确认是分钟级。

**Q：AI 助手把作品做砸了怎么办？**
截止前可以改好重交，最后一次提交算数。先交一版保底，再慢慢改，是个好习惯。

**Q：为什么提交要交会话记录？**
为了公平：证明作品是你的助手在这场比赛期间做的。记录会脱敏，你的隐私信息不会原文交出去。
